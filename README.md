# AgentWriter-AI

#How to run?

1. Clone the repo to your ocal machine.

```bash
git clone https://github.com/prajwalll/AgentWriter-AI.git
```

2. Navigate to your project directory.

```bash
cd AgentWriter-AI
```

3. Create your vertual environment.

```bash
python -m venv .venv
source .venv/bin/activate (To activate your environment)

// to remove env
rm -rf .venv
```

4. Install required dependencies.

```bash
pip install -r requirements.txt
```

5. Run the application

```bash
python main.py
```
